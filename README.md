# 🗺️ Iran Top Tourist Cities Map (Python & Basemap)

A Python script to visualize the geographical location of major tourist cities in Iran using `Basemap`, `Pandas`, and `Matplotlib`. 

> 📌 **Note:** In this visualization, the **size of each point (marker)** on the map is directly proportional to the **city's population**, giving a clear visual comparison of urban sizes.

---

## 🛠️ Dependencies & Requirements
To run this project, you need the following libraries:
- `Python 3.x`
- `pandas`
- `numpy`
- `matplotlib`
- `basemap`

> **Important Note:** Installing `basemap` via `pip` can sometimes cause issues due to C library dependencies. It is strongly recommended to install it using `conda`:
>
```bash
> conda install -c conda-forge basemap
>
